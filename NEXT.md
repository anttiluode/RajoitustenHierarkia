# NEXT — make the hierarchy earn itself

Gates 0 and 1 are calibration assays. They show that interventions can distinguish a state-conditioned/delayed factorization from simpler partial models when the world is actually generated by that factorization.

That is not enough.

## Gate 2 — the generic history attacker

A strong objection is obvious:

> “You do not have a hierarchy. You just have a linear dynamical system with memory.”

So give that objection teeth.

Train a generic VAR / lagged state-space model on the same trajectories. It may use enough lags to span every candidate delay and enough parameters to fit the base world very well, but it is **not** told that some coefficients belong to geometry and others to long-range wiring.

Required comparison:

```text
factorized model:
    x + Gx + Cx[t-d] + input

history attacker:
    x[t], x[t-1], ..., x[t-k] + input
```

Then test transfer after:

```text
rewire C
warp G
change delay
combine all three
```

Important fairness rule: the generic model may recalibrate from the same tiny post-change calibration budget used by the factorized model.

Measure:

- held-out next-state NMSE;
- calibration samples required;
- parameter count;
- transfer after unseen rewiring;
- transfer after unseen geometry warp;
- transfer after changed delay.

**Kill the hierarchy claim if the generic history model transfers just as well at comparable data/parameter cost.**

If factorization wins only because it is handed the changed `G` and `C`, say so. The interesting question is whether exposing the constraint layers buys compositional transfer rather than merely encoding privileged information.

## Gate 3 — selectively maintained dynamical islands

Only after Gate 2 should the repository return to `SpectralIslandsV2`.

Introduce several overlapping mode packets with similar dominant frequencies but different causal futures. An island earns identity only if it survives at least one substrate change while remaining distinguishable by a dynamical fingerprint such as:

```text
return dynamics
response latency
phase relation
transition probabilities
controllability
held-out poke response
```

Frequency-only identity is an explicit attacker.

## Gate 4 — constraint ordering

Test whether the same final operator can be reached through different causal orderings.

For example:

```text
geometry → wiring adaptation → local gain
```

versus

```text
local gain → wiring adaptation → geometry
```

If only the final matrix matters, “hierarchy” is unnecessary language. If history/order changes reachable dynamics under the same endpoint budget, the ordering has earned explanatory work.

## Gate 5 — bounded observer

Only after the physical hierarchy exists, place an `AlternativeNeuron`-style observer inside it.

The observer gets cheap residuals, expensive addressed measurements, reversible interventions, medium memory, and slow structural allocation. Ask whether active probing can identify which constraint layer changed more cheaply than global observation.

**Do not add consciousness, holography, or biological equivalence. First make the operators confess.**
