# NEXT — make the hierarchy earn itself

Gate 0 is only a calibration assay: the synthetic generator explicitly contains the interaction the hierarchy model is designed to recover. The next gates must remove that comfort.

## Gate 1 — geometry versus wiring under propagation

Build a delayed neural-field / graph-wave world with geometry and long-range wiring controlled independently.

Required interventions:

```text
same geometry, rewire long edges
same wiring, warp geometry
same both, change conduction delay
same all above, change local gain
```

Readouts:

- wave direction;
- arrival latency;
- spatial wavelength / spectrum;
- prediction of a held-out pulse response.

Attackers:

- geometry eigenmodes;
- connectome eigenmodes;
- flat `G+C` model;
- smooth low-frequency null basis;
- state-dependent delayed model;
- oracle simulator.

A useful result is not “our model reconstructs the map better.” It is “these models reconstruct similarly, but a controlled intervention makes their future predictions diverge, and one survives.”

## Gate 2 — selectively maintained dynamical islands

Introduce several overlapping mode packets with similar dominant frequencies but different causal futures.

An island earns identity only if it survives at least one substrate change while remaining distinguishable by a dynamical fingerprint such as:

```text
return dynamics
response latency
phase relation
transition probabilities
controllability
held-out poke response
```

Frequency-only identity is an explicit attacker.

## Gate 3 — constraint ordering

Test whether the same final operator can be reached through different causal orderings.

For example:

```text
geometry → wiring adaptation → local gain
```

versus

```text
local gain → wiring adaptation → geometry
```

If only the final matrix matters, “hierarchy” is unnecessary language. If history/order changes reachable dynamics under the same endpoint budget, the ordering has earned explanatory work.

## Gate 4 — bounded observer

Only after the physical hierarchy exists, place an `AlternativeNeuron`-style observer inside it.

The observer gets cheap residuals, expensive addressed measurements, reversible interventions, medium memory, and slow structural allocation. Ask whether active probing can identify which constraint layer changed more cheaply than global observation.

**Do not add consciousness, holography, or biological equivalence. First make the operators confess.**
